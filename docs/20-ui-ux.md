# UI/UX Specification

## Chat
- New conversation
- Conversation history
- Streaming response
- Source/citation display
- Copy response
- Feedback
- Retry
- Loading state
- Error state
- Responsive/mobile layout

## Accessibility
- Keyboard navigation
- Clear focus states
- Screen-reader-friendly controls
- Sufficient contrast
- Text resizing

## Source display
For university answers, show a compact source card such as:
Document title — page X — effective date if known.
