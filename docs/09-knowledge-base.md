## Source governance
Every document should have an owner, status and effective date where available.

Prefer:
1. Latest applicable official notice
2. Current official handbook/regulation
3. Other approved official source
4. Older source only when still applicable

Conflicting documents must not be silently merged. Surface the conflict or select the
latest verified applicable document according to an explicit policy.
