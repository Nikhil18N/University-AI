SRU Buddy widget: demo page

This page stands in for any SR University web page. The chat bubble in the corner is the widget version of SRU Buddy: the same assistant as the website, in a compact window.

Add it to a page

Paste this one line just before </body>:

<script src="https://university-ai-companion.vercel.app/widget.js" defer></script>

Optional: data-position="left", data-color="#1d4ed8", data-label="Ask SRU Buddy", data-greeting="...", data-open="true". From JavaScript: SRUBuddy.open(), SRUBuddy.close().
